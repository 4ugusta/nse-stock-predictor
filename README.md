# Indian NSE Stock Predictor

A comprehensive Python-based stock analysis platform for the Indian NSE market. Features technical analysis, trading signals, stock screening, news sentiment analysis, and both CLI and web interfaces.

## Features

- **Technical Analysis**: RSI, MACD, Moving Averages (SMA/EMA), Bollinger Bands, Support/Resistance levels
- **Trading Signals**: Buy/Sell signals with entry, target, and stop-loss levels
- **Stock Screener**: Pre-built and custom screening with multiple filters
- **News & Sentiment**: Aggregated news from Google News, MoneyControl, Economic Times with VADER sentiment analysis
- **Multiple Interfaces**: Command-line (CLI) and Streamlit web dashboard
- **Data Sources**: Yahoo Finance (free) with optional Zerodha Kite Connect (real-time)

## Installation

### Prerequisites

- Python 3.11 or higher
- pip or uv package manager

### Install

```bash
# Clone or navigate to the project
cd Indian-Stock-Predictor

# Create virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install dependencies
pip install -e .

# Or with uv (faster)
uv pip install -e .
```

## Quick Start

### CLI Usage

```bash
# Analyze a stock
nse-predict analyze RELIANCE

# Analyze with specific style
nse-predict analyze HDFCBANK --style positional --indicators

# View market overview
nse-predict market

# Screen stocks
nse-predict screen --preset oversold_bounce
nse-predict screen --rsi-oversold --above-200sma

# List available presets
nse-predict presets

# Fetch news
nse-predict news
nse-predict news --symbol INFY

# Manage watchlist
nse-predict watchlist add -s RELIANCE
nse-predict watchlist show
```

### Web Dashboard

```bash
# Start Streamlit dashboard
streamlit run src/stock_predictor/presentation/web/app.py

# Opens at http://localhost:8501
```

## Configuration

### Environment Variables

Copy `.env.example` to `.env` and configure:

```bash
cp .env.example .env
```

### Zerodha Kite Connect (Optional)

For real-time data, configure Kite Connect credentials:

```ini
KITE_API_KEY=your_api_key
KITE_API_SECRET=your_api_secret
KITE_USER_ID=your_user_id
KITE_TOTP_KEY=your_totp_secret
```

Without Kite Connect, the app uses Yahoo Finance (free, 15-min delayed data).

## Trading Styles

The predictor supports three trading styles:

| Style | Timeframe | Best For |
|-------|-----------|----------|
| Intraday | Same day | Quick trades, scalping |
| Swing | 2-10 days | Short-term trends |
| Positional | Weeks-months | Trend following |

## Screener Presets

| Preset | Description |
|--------|-------------|
| `oversold_bounce` | RSI < 30, above 200 SMA |
| `breakout_candidates` | Near 52-week high, bullish MACD |
| `trend_followers` | Above 50 & 200 SMA, uptrend |
| `value_plays` | Near 52-week low, RSI recovering |
| `momentum_stocks` | Strong MACD, RSI > 60 |
| `squeeze_plays` | Bollinger Band squeeze |

## Technical Indicators

### Implemented

- **Moving Averages**: SMA & EMA (9, 21, 50, 200 periods)
- **RSI**: 14-period with overbought/oversold zones
- **MACD**: 12/26/9 with histogram and crossover detection
- **Bollinger Bands**: 20-period with squeeze detection
- **Support/Resistance**: Pivot points and key levels

### Signal Generation

Signals are generated by combining indicator scores with style-specific weights:

```
Signal Score = (MA × 0.20) + (RSI × 0.20) + (MACD × 0.25) + (BB × 0.15) + (S/R × 0.20)
```

| Score Range | Signal |
|-------------|--------|
| > 0.7 | Strong Buy |
| 0.3 to 0.7 | Buy |
| -0.3 to 0.3 | Hold |
| -0.7 to -0.3 | Sell |
| < -0.7 | Strong Sell |

## API Reference

### Python API

```python
from stock_predictor.infrastructure.data_providers.yahoo_provider import YahooDataProvider
from stock_predictor.analysis.signals.signal_generator import SignalGenerator
from stock_predictor.core.entities.signal import TradingStyle

# Fetch data
provider = YahooDataProvider()
data = provider.get_historical("RELIANCE", period="1y")

# Generate signal
generator = SignalGenerator()
signal = generator.generate(data, "RELIANCE", TradingStyle.SWING)

print(f"Signal: {signal.signal_type.value}")
print(f"Entry: ₹{signal.entry_price}")
print(f"Target: ₹{signal.target_price}")
print(f"Stop Loss: ₹{signal.stop_loss}")
```
